<h2 align="center">📱 Game Overview</h2>

<p align="center">
Guess the randomly generated number within your selected range using limited attempts.<br>
Clean UI. Smooth gameplay. Policy-compliant monetization.
</p>

---

<h2 align="center">✨ Features</h2>

<p align="center">

🎮 Simple and responsive gameplay<br>
⚡ Built using Flame Game Engine<br>
📵 Fully offline game logic (no backend)<br>
📢 Smart AdMob integration<br>
🔐 UMP Consent flow supported<br>
🧼 Clean architecture (UI separated from logic)<br>
📦 Optimized release build (R8 + split-per-abi)

</p>
